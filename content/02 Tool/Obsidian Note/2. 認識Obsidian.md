# 初始設定

選擇創建資料夾名稱，該資料夾可以視為一個資料庫，資料庫之間是獨立的，後期要做圖譜或是聯接是無法做到的，因此創建時需特別留意，知識需如何分類

# 特殊文件夾

創建後，該路徑下就會出現這個資料夾，並預設產生一個 *. obsidian*  資料夾，裡面負責存儲關於 Obsidian 的所有設定資訊

- hotkeys. json：快捷鍵設定
- plugins 資料夾：插件安裝位置
- Themes 資料夾：主題安裝位置

Tips：若要在其他資料庫沿用設定，可以透過複製 *. obsidian* 資料夾到新資料夾，就可以沿用設定

# 快捷鍵

- 設置：CMD+,
