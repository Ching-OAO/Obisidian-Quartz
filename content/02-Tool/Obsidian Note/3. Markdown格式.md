# 常用語法

## 標題

* `# 文字`：一級標題，最多可以到６個 `#`，也就是六級標題
* `# 一級標題`
* `## 二級標題`
* `###### 六級標題`

## 加粗

`**文字**` / `__文字__`：要加粗文字的左右各２個星號 `*/_` 夾住，例如：**加粗**

## 斜體

`*文字*` / `_文字_`：要斜體文字的左右各１個星號 `*/_` 夾住，例如：*斜體*

## 刪除線

`~~文字~~`：要加粗文字的左右各２個波浪符 `~` 夾住，例如：~~刪除線~~

## 有序列表

`1. 文字`：數字 ＋ `.` ＋ 空格 ＋ 文字

1. A
2. B
3. C

## 無序列表

`* 文字` / `- 文字`：`*/-` ＋ 空格 ＋ 文字

* A
* B
* C

## 縮排控制

`點擊Ｔａｂ`：可透過 Ｔａｂ鍵來控制縮排

1. A
	1. a
	2. b
2. B
	* 123
	* 456
	* 789

## 引言

`> 文字`：`>` ＋ 空格 ＋ 文字

> 引用

## 分隔線/水平線

`___/***/---`：這三種都可以

___

## 連結

`［連結名稱］（連結來源）`：中間不需空格

## 特殊符號需跳脫（escape)

\ + 特殊符號：若要僅作為字符顯示 \*、\_、\[] 等符號，需用 `\*`、`\[` 方式跳脫。

## 行內程式碼

\`文字\` ：用於單行內程式碼，底部會有灰底呈現。另外針對特殊符號，若僅僅作為顯示，不觸發他的 Markdown 規則，也可以用這個方法，舉例：`#`, `_`, `*`


## 程式碼區塊

前後用三個\`\`\` 包住，可跨行，第一行後面打上程式名稱可以指定顯示該程式語言的高亮規則

\`\`\`SQL

文字

\`\`\`

```SQL
select *
from MS0200 a with(nolock)
where CompanyNo = '310'
order by 1
```


## 核取方格

`- [ ] `：`-` + 空格 + `[` ＋ 空格 ＋ `]` ＋空格 ＋ 文字，代表未完成

`- [Ｘ] `：`-` + 空格 + `[` ＋ Ｘ ＋ `]` ＋空格 ＋ 文字，代表已完成

- [ ] A
- [x] B

Tips：可透過設定鍵盤快捷鍵，快速調整格式，例如：CMD＋Ｌ，直接呼叫核取方格

# Markdown 書寫格式建議

段落與段落之間建議空一行，是較為嚴謹的書寫格式，可以理解為只要內容結構變了（段落、清單、標題、區塊引言、程式碼區塊），就空一行

* 每段文字內容之間都空一行
* 遇到不同語意結構就空一行（清單→表格、表格→段落）
* 撰寫後切換預覽檢查渲染結果，看是否該分開

| 使用情境             | 是否需要空行 | 說明                    |
| ---------------- | ------ | --------------------- |
| 段落之間             | ✅ 需要   | 否則會合併成一段              |
| 標題與段落之間          | ✅ 建議加  | 不加雖然有時可正常解析，但可讀性差     |
| 清單與段落之間          | ✅ 建議加  | 避免渲染成錯誤的清單項           |
| 區塊引言與段落          | ✅ 建議加  | 否則換行可能失效              |
| 表格與其他區塊          | ✅ 建議加  | 否則可能會被當成普通文字處理        |
| 程式碼區塊（```) 與其他內容 | ✅ 建議加  | 更容易區分範圍               |
| 不同類型清單之間         | ✅ 建議加  | 例如數字清單 + 點清單          |
| 行內元素（粗體、斜體、超連結）  | ❌ 不需要  | 它們是段落**內**的修飾，不影響區塊邏輯 |
