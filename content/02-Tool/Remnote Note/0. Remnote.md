- RemNote Tutorial
    - 本質上是一個基於**大綱**的筆記工具，文​​件由一系列可以縮排形成層次結構的項目符號點組成。
這樣可以輕鬆地根據您的需求詳細地組織您的筆記
- Rem
    - 是這個知識庫軟體的最小筆記單位，每段文字都是一個`Rem` 
    - 所有層次結構中的 Rem可以使用[Reference](Basic%20Operations/RemNote%E4%B8%BB%E8%A6%81%E5%8A%9F%E8%83%BD/Reference.md)和[Tags](Basic%20Operations/RemNote%E4%B8%BB%E8%A6%81%E5%8A%9F%E8%83%BD/Tags.md)連結在一起
    - 在`Rem`之上的一切歸納功能都可以視為是貼上類別標籤 (EX:文件,資料夾,ToDo,Date,etc.)
- 建立Folder 或 Document
    - 按下左側功能列的  *Create* ，可選要建立Folder 或 Document
    - Document
        - 將多個[Rem](Basic%20Operations/Rem.md)標註成一個文件，方便閱讀(可以理解為賦與一個屬性是Document的標籤)
    - Folder
        - 用以歸納整理多個[Document](Basic%20Operations/%E5%BB%BA%E7%AB%8BFolder%20%E6%88%96%20Document/Document.md)，當製作筆記時，遇到需要Reference到特定資料夾時，可直接跳到該層資料夾之內(可以理解為賦與一個屬性是Folder的標籤)
- FlashCards記憶功能
    - [~Source]()
        - [Creating Flashcards | RemNote Help Center](https://help.remnote.com/en/articles/6025481-creating-flashcards)
    - 透過間格重複回憶來強化知識記憶
    - 透過[FlashCards](Basic%20Operations/RemNote%E4%B8%BB%E8%A6%81%E5%8A%9F%E8%83%BD/FlashCards.md)快捷鍵建立記憶閃卡
    - 建立後，該文件的右上角會出現卡片圖示及目前有激活的閃卡數量，下拉可定義該閃卡的屬性狀態
    - 屬性狀態有5種，考試、激活、維持、暫停、未定義
    - 左側功能列有 *FlashCards* ，可連結至[FlashCards Home](Basic%20Operations/FlashCards%20Home.md)
- FlashCards Home
    - 所有FlashCards會存在這裡
    - 該頁面根據上中下分成三個部分
        - 上部是統計資料，能看到每日練習閃卡的統計數據，總結本週的學習進度，點擊右上角「 *Practice Today`s Cards* 」可以開始練習全域有啟用的閃卡
        - 中部是回到文件，會出現有設定優先級的文件
        - 下部是顯示所有文檔，按優先順序排序，如果按一下右側的灰色小箭頭，則會顯示子文檔 ，透過點擊左側的優先級圖示來變更任何文件的優先級，或使用 *「Practice」* 按鈕和右側的下拉式功能表開始練習或配置它。中間是文件中目前有多少張卡片以及您對它們的了解程度的摘要；將滑鼠懸停在每個彩色條上即可查看該學習狀態的說明
- RemNote主要功能
    - /-Menu
        - /-選單，多數功能可透過開啟選單中找到，透過輸入筆記時按`/`(或`\`) 開啟。 只需鍵入所需功能選項的名稱並選擇即可
    - Omnibar
        - 多功能欄，是在 RemNote 中完成幾乎所有任務的最快方式
        - 其具有[/-Menu](Basic%20Operations/RemNote%E4%B8%BB%E8%A6%81%E5%8A%9F%E8%83%BD/_-Menu.md)上的所有功能，以及所有RemNote功能導覽，還可對多個 Rem 執行操作
        - 呼叫多功能選單後會出現一個搜尋視窗，藉由輸入幾個字母或您想要執行的操作描述，找到該功能並執行他(右側將顯示每個項目的 *簡碼* )
        - 直接按下`Crtl+K` 呼叫多功能選單
        - 如果執行的操作針對單一或多個Rem，先作選取，再按下`Crtl+K` 呼叫多功能選單
(若是操作針對多個 Rem，甚至不必按 Ctrl+K 來開啟多功能欄，只需直接輸入簡碼或說明，多功能欄就會自動開啟)
        - [Omnibar](Basic%20Operations/RemNote%E4%B8%BB%E8%A6%81%E5%8A%9F%E8%83%BD/Omnibar.md) 和 [/-Menu](Basic%20Operations/RemNote%E4%B8%BB%E8%A6%81%E5%8A%9F%E8%83%BD/_-Menu.md) 包含許多相同的操作，關鍵差異在於 /-Menu 僅包含對當前 Rem 進行操作的功能，並且一次只能用於對一個 Rem 進行操作  
    - Reference
        - 參考：創建引導到另一個 Rem 的連結，點擊連結將引導到包含該Rem 的文件
        - 輸入`[[` or `++` or `@` +所需的關鍵字，可搜尋出與關鍵字相關的Rem，產生參考
            - EX：[Rem](Basic%20Operations/Rem.md)
        - 如果您正處於要做參考的 Rem 文件時，也可以選擇直接複製貼上。點擊要參考的目標 Rem(但不做反白)，然後按 Ctrl+C，會顯示「 *Copied to clipboard* 」。再將遊標放在要插入 Rem 參考的位置，按 Ctrl+V，將貼上參考
        - 正確產生連結後，字會變成藍色。點擊會連結到包含該Rem 的文件並用藍框標示。
            - EX：[Rem-A is note A.]()
        - 連結的文字後方會有灰色方格標籤，數字代表引用次數，點擊可顯示目前有對這個Rem做Reference的內容 (為雙向連結)
        - 對建立完Reference的文字按右鍵，可顯示引用的 Rem 及其子項目的內容 
        - 當被參考的Rem修改時，參考的資料也會同步修改
        - 如果您確實想要鍵入字元`[[`、`++`或`@`，而不是建立引用，只需隨後按 Escape 鍵即可
    - BackLinks
        - 反向連結：在 RemNote 中引用另一個 Rem 時，無論您使用[Reference](Basic%20Operations/RemNote%E4%B8%BB%E8%A6%81%E5%8A%9F%E8%83%BD/Reference.md)、[Links](Basic%20Operations/RemNote%E5%9F%BA%E6%9C%AC%E5%BF%AB%E6%8D%B7%E6%93%8D%E4%BD%9C/Links.md)、Protal或[Tags](Basic%20Operations/RemNote%E4%B8%BB%E8%A6%81%E5%8A%9F%E8%83%BD/Tags.md)，RemNote 都會在兩個 Rem 之間建立雙向連結。也就是說，RemNote 既識別 A 連接到 B，又識別 B 連接到 *A* 
        - 在已引用的任何 Rem 的右側，存在灰色框，其中有數字代表該Rem被引用的次數。點擊此數字將顯示反向連結列表。您可以點擊反向連結跳到那裡
        - 當點進文件或 Rem 時，您將在頁面底部看到更詳細的反向連結清單
        - 文本參考的反向連結  ，框選要查找其文本參考的文字，然後選擇文本編輯工具列上的放大鏡圖標進行查找 
    - Tags
        - 標籤：可讓您以跨越知識庫中所有文件和層次結構的方式標記這個Rem 是什麼
例如標記貓是一種「哺乳動物」，或是標記有時效的待辦事項一個「緊急」標籤  
        - 輸入`##` +所需的標籤名稱
        - `##`標籤搜尋選單為方便搜尋，僅顯示以下 Rem
            - 曾被用作標籤  
            - 屬性或模板
            - 搜尋名稱與您輸入的名稱完全相同
        - 標籤本身也是Rem，您可以存取它們，透過更改文字來重新命名它們，將它們移至層次結構中等
        -  標籤可作過濾用途
            - 以滑鼠右鍵按一下該標籤的某個實例，然後選擇「 *Filter Document by This Tag.* 」 
            - 按 `Crtl+F`，從搜尋模式下拉清單中選擇「 *Filter* 」，然後選擇要篩選的標籤
        - 所有標籤會彙整在 *All Note* 的 *Tags* 中
    - Protals
        - 傳送門：向不同文件中的其他 Rem 開啟窗口，允許相同的內容出現在多個位置
        - 傳送門內容會在左側顯示藍色粗線，當遊標位於傳送門內時，整個周圍會出現藍色框
        - `((` +要顯示的Rem
            - --------------------- Portal ---------------------
                - Works
        - 點擊Protal裡面的內容可做修改(會同步修改原Rem的資料)

    - FlashCards
        -  Basic cards 
            - 基本卡→字體顯示為一般
            - `==` or `>>` +要記憶的內容，正向記憶卡片
            - `<<` +要記憶的內容，反向記憶卡片
            - `<>` +要記憶的內容，雙向記憶卡片
            - `=-` +要記憶的內容，不建立記憶卡片
        -  Concept cards
            - 概念卡::字體自動顯示粗體
            - `::` +要記憶的內容
        -  Descriptor cards
            - 描述卡;;字體自動顯示斜體
            - `;;` +要記憶的內容
        - Cloze
            - 克漏字、 *occlusions、cloze deletions* 
            - 輸入`{{` +要記憶的內容，可挖空成克漏字
            - `{{` +要記憶的內容、框選後輸入`{` 、框選後用滑鼠點克漏字選項[...]
        -  Multi-Line Cards
            - 輸入任意FlashCards符號，在按下Enter即可
            - `>>>` or`:::` or`;;;` 
            - 既有一個有父子關係的Rem，從 /-選單中選擇 Card Item 選項，或按 Ctrl+Alt+R，再次點選可關閉 Multi-Line Cards 狀態
        -  Multiple-Choice Cards
            - `>>A` +要記憶的內容
            - A選項默認正確答案，往下可新增其他選項(錯誤答案)
            - 點擊選項符號可更改是否為正確選項
        - 設定閃卡在複習時能有輸入答案的文字方塊
            - 一般情況不需輸入，根據記憶狀況回覆記憶結果即可

- RemNote技巧
    - 使用概念(Concept)/描述詞(Descriptor)框架建立知識
        - Concept
            - 概念：需要被描述的主體，透過主體組成對世界的理解―概念通常標示 **粗體** 
        - Descriptor
            - 描述詞：代表概念的屬性，用以描述概念―概念通常標示  *斜體*  
        - 概念之間彼此相關聯，透過Reference
        - 當學習或解析新領域知識時，會經歷3步驟
            1. 將吸收的資訊分解為按層次排列的概念
            2. 針對這些概念定義(理解)描述詞
            3. 根據概念之間的關係，使用 [Reference](Basic%20Operations/RemNote%E4%B8%BB%E8%A6%81%E5%8A%9F%E8%83%BD/Reference.md)或[Tags](Basic%20Operations/RemNote%E4%B8%BB%E8%A6%81%E5%8A%9F%E8%83%BD/Tags.md)將概念歸納連結在一起
    - Universal Descriptor
        - 通用描述詞：使用概念描述詞框架作筆記，會經常出現的描述詞，習慣用前綴**~**符號來表示它們
        - 兩種方法編寫通用描述符
            - 建立一個Rem，在文件內產生Reference
            - 建立一個Rem，並賦予屬性。後續引用它時，會自動產生抽認卡，而無需輸入`;;`等操作，但該Rem無法在抽認卡的最前面再添加任何其他詳細資訊
        - 這些通用描述詞可建立一個Rem將其都收集記錄起來，透過顏色分類及維護
    - 標籤運用
        - **屬性：**標籤可設定屬性，會自動包含在套用該標籤的任何 Rem
        - **表格：**標籤和屬性搭配，可建立出表格，鍵入`/table`並選擇要用作資料來源的標籤
        - **模板：**標籤可以附加一個或多個模板。模板是一組任意 Rem，可以一次性將其全部添加到帶有該標籤的任何 Rem 中
- RemNote基本快捷操作
    - Links
        - 連結：點擊任意文字時，可以快速存取網站或其他 Rem  
        - 框選目標文字，並點擊「 *連結* 」按鈕或按 `Ctrl+Alt+K` 
            - 在跳出的文字框內貼上 URL 並按 Enter―完成連結建立
            - 在跳出的文字框內搜尋知識庫中Rem，搜尋知識庫，並按 Enter―完成Rem的連結
        - 連結建立完成後，查看筆記會帶有下底線，EX：[Links](https://help.remnote.com/en/articles/7042107-links) 
    - Quote (or Inline Code) 
        - 輸入```` ，可輸入單行的Code，或用於將MarkDown格式作為筆記內容輸入
    - Date
        - 輸入`!!` ，可選擇日期
        - 日期本身也是一個標籤，會出現Tag在每日筆記的對應日期裡
        - 可應用在待辦事項的規劃
    - LaTeX Syntax
        - `$$` +輸入數學方程式，EX：$F=MA$
        - 單行模式：`$`+數學方程式+`$`     ，整串複製貼入(不能手Key)，金錢符號前後必須至少有一個空格  
        - 區塊模式：`$$`+數學方程式+`$$` ，整串複製貼入(不能手Key)，金錢符號前後必須至少有一個空格
        - 輸入特殊符號可參考[Supported Functions · KaTeX](https://katex.org/docs/supported.html)
        - 化學反應式也支援，使用`\ce`巨集，`$\ce + { 化學反應式 }$` 整串複製貼入(不能手Key)，EX：$\ce{2 H2O}$
